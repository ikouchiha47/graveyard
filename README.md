# graveyard

Old learning projects, archived here as full, self-contained branches —
not a merge, not a submodule pointer. Each branch below is that
project's own real commit history, with real original dates, pushed as
a branch (not a directory) in this one repo. Once a project's branch is
here, its history is fully owned by this repo — nothing depends on the
original repo continuing to exist.

```sh
git clone https://github.com/ikouchiha47/graveyard.git
cd graveyard && git checkout <name>   # e.g. git checkout chathall
git log                                # real history, real dates
```
